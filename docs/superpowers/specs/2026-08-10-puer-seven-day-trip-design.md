# 武汉出发普洱七日自驾旅行网页设计

## 目标与约束

- 出发地：武汉。
- 时间：2026 年 9 月，7 天 6 晚。
- 预算：每人约 8,000 元。
- 当地方式：自驾；住宿采用“城区舒适酒店 + 景迈山一晚以上品质民宿”的混住策略。
- 体验必须兼顾茶山古村、雨林动物、咖啡美食，避开纯拍照式网红内容。
- 必须分别提供单人和双人计划，并在动态地图上查看每日真实路线。
- 地点、坐标和道路均需可核验；实时价格、开放时间和班次不得伪装为固定事实。

## 方案比较

### 方案 A：纯静态单文件 HTML

优点是可以离线保存；缺点是地图只能做示意，路线与内容难以联动，不能满足真实动态路线的核心诉求。

### 方案 B：交互式单页网站 + 预核验道路数据（采用）

使用 React 单页承载内容，Leaflet 显示 OpenStreetMap 瓦片；道路轨迹在制作阶段从 OSRM 获取并保存为 GeoJSON。运行时不需要商业地图密钥，即使路径服务临时不可用也不会丢失路线。页面提供一人/两人和 Day 1–7 两个控制维度。

### 方案 C：商业地图 SDK + 实时驾车规划

实时性更强，但需要用户申请密钥，存在配额、域名白名单和隐私配置成本。当前一次性旅行计划没有必要引入。

## 路线结构

### Day 1：武汉 → 昆明 → 普洱思茅

以飞机和中老铁路衔接为推荐方式。页面把航空段、铁路段和当地落地段分层展示；具体班次在出发前 30 天以航空公司和 12306 为准。抵达后仅入住、取车或确认次日取车，不安排夜间山路。

### Day 2：思茅城市生活与咖啡原产地

五一集贸市场早餐和食材观察，思茅老街/戴家巷慢走，小凹子咖啡庄园进行种植与处理体验。庄园参观需要提前联系确认，不把社交媒体价格当作固定票价。

### Day 3：太阳河森林与犀牛坪

从思茅白天往返普洱太阳河森林公园犀牛坪景区，安排 4–5 小时森林步行和动物观察。说明展示区动物与野生观察的区别，雨天不延伸到非开放林道。

### Day 4：思茅 → 澜沧 → 惠民镇

转入景迈山前置住宿日。午后抵达惠民镇或景迈山外围，避免天黑后驶入村寨山路；完成“景迈山预约服务”小程序预约核验。

### Day 5：景迈山古茶林与村寨

只走开放道路和公共步道，核心为大平掌古茶林、糯岗古寨、翁基古寨与芒景村。节奏是茶林解释、村寨午餐、与茶农预约品茶，不以摄影机位为目标。无人机仅在取得许可时使用。

### Day 6：景迈山 → 澜沧 → 思茅

上午保留给茶山或雨雾天气的补偿时段，午前下山，白天返回思茅。晚间在新兴街或五一夜市选择本地菜，并整理次日返程。

### Day 7：普洱 → 昆明 → 武汉

还车后乘中老铁路至昆明，再转武汉航班。联程至少预留 4 小时；若机票时刻不合适，页面提示把昆明作为一晚缓冲而不是冒险赶程。

## 单人与双人差异

单人版优先小型自动挡、城区连锁或稳定评分酒店、每天日落前 60 分钟结束驾驶、双联系人报平安。预算按一人独享房间和车辆计算。

双人版优先紧凑型 SUV 或通过性较好的轿车，住宿以大床/双床房计，油费和车辆费用共享，山区驾驶可轮换。预算既显示双人总额，也显示人均金额。

## 内容结构

1. 首屏总览：出发信息、预算、地图和模式切换。
2. 七天路线：时间轴与地图双向联动。
3. 吃穿住行：九月雨季装备、在地饮食原则、住宿区域与自驾规则。
4. 预算账本：单人和双人逐项区间及机动金。
5. 真实地点簿：名称、类型、坐标、来源、预约状态和“为何值得去”。
6. 出发前清单：订票、租车、景迈预约、天气和道路复核时间点。

## 数据与错误处理

地点数据是本地 TypeScript 常量，包含稳定 ID、名称、坐标、类别、来源 URL 和核验日期。道路几何是本地 GeoJSON；地图瓦片加载失败不影响文字路线。所有费用使用最小/最大值和核验日期，页面不提供虚假的“一键预订”。

## 验证标准

- 自动化测试验证 7 天数据完整、所有地点有合法经纬度与来源、单人/双人预算计算正确。
- 构建输出无 TypeScript 或打包错误。
- 360px、768px、1440px 三档布局可读，地图之外存在等价的文字路线。
- 键盘可切换模式和日期，焦点清晰，减少动画偏好有效。
- 地图点击每一天时只强调当天路线，并能播放/重播道路描画动画。

## 自检结果

没有待定字段；路线范围、用户模式、内容边界、地图降级策略和预算口径均已明确。具体交通班次、实时票价、景区营业时间和道路状态被明确列为出发前复核项，不作为页面中的永久事实。
