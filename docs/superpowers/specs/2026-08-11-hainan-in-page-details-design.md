# 海南地图站内详情设计

## 目标

让地图成为唯一主界面：播放暂停后，用户可以点击任意后续地图点、顶部 Day 节点或当前行程卡片，在站内查看完整图文；关闭详情后仍保持暂停，不篡改原播放进度。

## 交互

- 地图点、Day 时间轴按钮、播放卡片的“查看完整图文”共用一个 React 详情弹层。
- 打开详情时暂停动画并把地图镜头移到预览地点；不修改当前播放阶段和已绘制路线。
- 关闭详情不自动续播；点击底部“继续”后从原进度继续。
- 时间轴点击当天首个非交通、非住宿地点；只有住宿或交通的日子回退到当天第一点。
- 外部链接降级到详情底部“资料来源”，主要信息必须在站内完整呈现。

## 内容

- 地点详情包含实景图、时间、停留、路线步骤、实用提醒、九月天气退路。
- 结合用户提供的小红书笔记，为每个 Day 增加路线顺路的吃喝候选；万宁笔记只用于万宁，三亚笔记只用于三亚。
- 酒店详情补充海棠湾君悦的湾区选择逻辑和官方设施信息；价格不作为主要信息。
- 免税购物作为海棠湾的可选分支，不塞进主路线。

## 边界

- 不新增未经坐标核验的餐厅地图点；餐厅以站内候选清单呈现。
- 不复制小红书笔记图片；沿用现有已归档、已标注来源的本地实景图。
- 不把小红书链接做成主要 CTA。
