# 地点多图故事与真实道路设计

## 目标

把当前“文字很完整、视觉和路线不够可信”的海南地图升级为三个一致的体验：地点弹框能用连续图片讲清楚一个地方，自驾动画严格沿真实道路移动，安静慢游仍然拥有值得期待的核心活动。

## 已确认方向

用户已确认直接实施，不再追加需求确认。采用以下组合方案：

1. 真实道路使用 OSRM / OpenStreetMap 预生成并缓存为本地 GeoJSON，不在浏览器运行时请求第三方导航接口。
2. 地点弹框使用 3–5 张真实来源图片的轮播；第一张是地点全貌，其余依次覆盖游玩动作、环境细节和实用信息。
3. 小红书图片只在能代表地点时进入首图；招牌、局部自拍或无法说明地点的图片降级为补充图或移除。
4. 线路仍保持 Plan A / Plan B 和两次换宿不变，只增强道路真实性和活动记忆点。

## 信息架构

### 地点图片故事

`Place.image` 继续代表首图，`Place.gallery` 保存补充图片。弹框将二者组合成有序图片故事：

- 全貌：海湾、酒店、渔港或植物园的环境建立镜头。
- 动作：慢走、乘船、咖啡／巧克力体验、泳池或海岸活动。
- 细节：青皮林、渔排、市场食物、酒店房型或现场入口。
- 每张图显示平台、作者／机构、标题和原始链接。

轮播提供上一张、下一张、缩略图、当前位置和键盘左右方向键；单图地点不显示多余控件。切换地点时自动回到第一张。

### 真实道路

新增可重复运行的路线生成脚本。脚本读取明确的途经坐标，调用 OSRM driving profile，使用 `overview=full&geometries=geojson`，把返回的道路坐标、距离、耗时和来源写入两个计划的本地 GeoJSON。

- 航班保留端点连线。
- 自驾段必须来自路由引擎，每段至少包含足以贴合道路的坐标密度。
- 酒店海岸短步行保留本地步行示意，但不再伪装为道路导航。
- 浏览器只读取本地 GeoJSON，避免公网 API 抖动影响首屏。

## 活动吸引力调整

### Plan A

- 石梅湾：从“海边慢走”升级为“九里文化海湾＋滨海青皮林＋海边书屋”，保留安静感并增加独特记忆点。
- 新村港：突出正规码头、疍家渔排、海上村落观察和新村镇午饭，不把猴岛等拥挤项目硬塞进来。
- 清水湾：把留白日写成晨间海岸、午间避晒、傍晚泳池／日落三个明确节奏。
- 免税城：保留为可选采购窗口，不再把购物描述成核心旅行高潮。

### Plan B

- 兴隆植物园：增加可可、香草兰、咖啡和巧克力制作等有参与感的体验，而不只是看植物。
- 土福湾：把两天酒店慢住拆成海岸、泳池、咖啡／下午茶和雨天室内替代，避免连续空白。
- 免税城同样降级为可选支线。

## 加载状态修复

地图实例初始化不得把已经完成的路线状态重新设为 `loading`。路线数据状态只由 GeoJSON 请求维护，Leaflet 与瓦片加载失败不阻塞本地路线和开始按钮；瓦片失败时显示轻提示。

## 测试与验收

- 单元测试确认重点地点至少三张图片且来源完整。
- 渲染测试确认弹框存在轮播控件、图片位置和来源链接。
- GeoJSON 测试确认所有自驾段包含高密度坐标、OSRM 来源、连通端点和合理距离。
- 回归测试确认地图初始化不会把路线状态重置为 loading。
- 浏览器验证总览、石梅湾、新村港、Plan B 兴隆、Day 4 实际道路、手机弹框和播放动画。

## 非目标

- 不接入实时交通或导航语音。
- 不在运行时依赖高德、百度或付费地图密钥。
- 不增加第四家酒店、不增加换宿次数、不恢复拥挤的打卡清单。
