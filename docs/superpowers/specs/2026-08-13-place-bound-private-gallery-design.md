# 地点专属私人图库设计

## 目标

修正私人小红书图库按城市混放的问题。用户打开某个地点的详情时，默认只看到与该地点有明确对应关系的图片；城市泛游、攻略拼图和无法确认具体地点的素材不能伪装成该地点实景。

## 交互设计

- 地点详情里的私人图库标题改为“当前地点 · 私人实景”。
- 默认模式只渲染 `placeIds` 包含当前 `place.id` 的图片，每张图仍是独立缩略卡片。
- 当前地点没有专属小红书图片时，不渲染私人图库；详情原有的地点实景图片继续保留。
- 专属图片多于 8 张时先展示 8 张，再允许展开。
- 图库底部提供“查看该城市全部素材”按钮。只有用户主动点击后，才进入城市总图库；总图库保留主题筛选和全部素材。
- 从总图库返回时，恢复当前地点的专属图片，不改变地图或详情弹窗状态。
- 点击任意图片进入大图预览，前后切换仅在当前可见集合内循环。

## 数据设计

`PrivateSocialImage` 增加 `placeIds: string[]`：

- 文件名、笔记标题或笔记主题能明确指向行程地点时，写入对应地点 ID。
- 只描述城市、区域路线、美食合集或未包含在行程中的地点时，`placeIds` 为空，只出现在城市总图库。
- 一个笔记明确覆盖两个行程地点时可写入两个 ID，但不根据城市相同关系自动扩散。

抓取脚本是地点绑定的唯一生成入口，重新抓取后不会丢失人工定义的映射规则。

## 组件边界

- `RouteMap` 向私人图库传递 `placeId`、`placeName` 和 `city`。
- `PrivateSocialGallery` 负责地点/城市两种视图、筛选、展开和预览。
- `private-social-gallery.ts` 只保存素材元数据和纯过滤函数，不包含 UI 状态。

## 验收标准

- 骑楼老街详情只出现骑楼素材，不出现海南东线攻略图。
- 神州半岛、石梅湾、兴隆市场、兴隆植物园、新村港、三正月酒店、鹿回头等已核验地点分别显示自己的素材。
- 城市泛游素材只能在主动打开城市总图库后出现。
- 390px 手机宽度无横向溢出；地点/城市切换、大图预览、前后切换均可用。
- 私人素材仍留在忽略目录，GitHub 公网分支不更新。
