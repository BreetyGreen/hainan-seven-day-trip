# 海南旅程本地私人素材版设计

## 目标

在不修改或部署 GitHub Pages 公网版本的前提下，为本地海南旅程网站增加一个私人素材模式。该模式使用下载到本机的小红书旅行图片，重点补充海景酒店、安静海岸、城市漫游和吃喝，并保持地图与现有旅行详情交互不变。

## 隔离方式

- 工作仅发生在本地分支 `codex/private-xhs-media`，不推送任何远端。
- `.env.local` 设置 `NEXT_PUBLIC_PRIVATE_MEDIA=1`，只影响本机开发服务器。
- 新下载图片放入 `public/private-hainan/`，该目录加入 `.gitignore`，不会被 Git 暂存或部署。
- 素材元数据保留原笔记链接、城市、主题和图片编号，便于核对及删除。

## 内容与视觉

- 私人素材库目标不少于 60 张图片，覆盖海口、万宁、陵水、三亚。
- 优先选择画面干净、海景突出、酒店环境清晰、少大字贴纸的图片。
- 私人模式使用单独的图片概览入口，并显示“LOCAL PRIVATE”标识。
- 图片按海景酒店、安静海岸、城市漫游、吃喝四个主题筛选。
- 默认展示 12 张，继续展开时再加载后续图片；点击进入大图预览，并能前后切换。

## 获取边界

- 只读取无需绕过登录、验证码或其他技术限制即可公开访问的图片。
- 不下载视频，不绕过防盗链；所有图片转为本地 WebP 预览。
- 下载脚本输出失败清单，单个笔记失败不阻断其他素材。

## 验收

- 私人目录和 `.env.local` 均不会出现在 Git 暂存范围。
- 私人模式至少展示 60 张图片，四个城市、四个主题均有内容。
- 单张 WebP 小于 400 KB，列表图片使用懒加载。
- 390px 手机宽度没有横向溢出，筛选、展开、预览和前后切换可用。
- 公网 GitHub Pages 的远端 `main` 提交保持 `d167861` 不变。
